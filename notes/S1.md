- A domain model is how to model the business logic. E.g. domain model = modelling how to handle the allocation of goods for customers (customer, buying team, product allocation, stock in warehouses, tracking shipments etc.)
- A Value Object is an object that is only identified by it's data (no unique id) -> in python immutable Dataclasse
- An entity is a domain object that has long-lived identity e.g. a 'batch' of purchase
- Domain exception : create Exception that bears domain meaning. Example : class OutOfStock(Exception)
- Repository Pattern : 
    - Dependency inversion on the ORM
    - Simple abstraction around permanent storage, easy to test for swap fakeRepo
